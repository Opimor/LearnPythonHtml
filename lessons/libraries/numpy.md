# numpy — работа с массивами чисел

## Что это
numpy — библиотека для быстрых вычислений с массивами (списками чисел). Вместо циклов `for` все операции работают сразу над всем массивом.

**`np.array()`** — превращает обычный список Python в numpy-массив. Пример:
```python
import numpy as np
a = np.array([1, 2, 3, 4, 5])
print(a * 2)  # [2 4 6 8 10] — умножило ВСЕ числа сразу
```

## Создание массивов
**`np.zeros()`** создаёт массив из нулей. **`np.ones()`** — из единиц. **`np.arange()`** — как `range()`, но возвращает массив. Пример:
```python
print(np.zeros(3))           # [0. 0. 0.]
print(np.ones(3))            # [1. 1. 1.]
print(np.arange(0, 10, 2))   # [0 2 4 6 8]
```

## Форма массива
**`.shape`** — свойство, которое показывает размеры массива (строки, столбцы). **`.reshape()`** — меняет форму. Пример:
```python
a = np.arange(6)
print(a.shape)           # (6,)
print(a.reshape(2, 3))   # [[0 1 2] [3 4 5]]
```

## Индексация
Работает как в обычном списке, но есть мощные фильтры. **`a[a > 3]`** — возвращает только числа больше 3. Пример:
```python
a = np.array([1, 5, 3, 8, 2])
print(a[a > 3])    # [5 8]
print(a[a % 2 == 0])  # [8 2] — только чётные
```

## Агрегации
**`.sum()`** суммирует, **`.mean()`** считает среднее, **`.max()`** / **`.min()`** — максимум и минимум. Пример:
```python
a = np.array([1, 2, 3, 4, 5])
print(a.sum())    # 15
print(a.mean())   # 3.0
print(a.max())    # 5
```
## Математические операции
С numpy можно применять математику ко всему массиву без циклов.

**`np.sqrt()`** — квадратный корень, **`np.exp()`** — экспонента, **`np.log()`** — логарифм. Пример:
```python
a = np.array([1, 4, 9, 16])
print(np.sqrt(a))   # [1. 2. 3. 4.]
```

## Линейная алгебра
**`np.dot()`** или **`@`** — матричное умножение. **`np.linalg.inv()`** — обратная матрица. Пример:
```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A @ B)           # матричное умножение
print(np.linalg.inv(A)) # обратная матрица
```

## Объединение массивов
**`np.concatenate()`** склеивает массивы. **`np.vstack()`** — по вертикали, **`np.hstack()`** — по горизонтали. Пример:
```python
a = np.array([1, 2])
b = np.array([3, 4])
print(np.concatenate([a, b]))  # [1 2 3 4]
```

## Случайные числа
**`np.random.rand()`** — числа от 0 до 1, **`np.random.randint()`** — целые числа. Пример:
```python
print(np.random.rand(3))               # [0.1 0.5 0.8]
print(np.random.randint(0, 10, 5))     # [3 7 1 9 2]
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Создать массив | `np.array([1, 2, 3])` |
| Массив из нулей | `np.zeros(5)` |
| Массив из единиц | `np.ones((3, 3))` |
| Диапазон чисел | `np.arange(0, 10, 2)` |
| Случайные числа | `np.random.rand(3, 3)` |
| Форма массива | `a.shape` |
| Сумма / среднее | `a.sum()` / `a.mean()` |
| Максимум / минимум | `a.max()` / `a.min()` |
| Фильтр | `a[a > 5]` |
| Изменить форму | `a.reshape(2, 3)` |
| Транспонировать | `a.T` |
| Матричное умножение | `a @ b` |
| Сохранить | `np.save('file.npy', a)` |
| Загрузить | `np.load('file.npy')` |

> 💡 **Зачем нужен numpy:** в 50–100 раз быстрее списков Python при работе с числами.


## Дополнительно: продвинутые приёмы

### Создание массивов (все способы)
```python
np.zeros(5)              # [0. 0. 0. 0. 0.]
np.zeros((2, 3))         # 2x3 нулей
np.ones((3, 3))          # единичная 3x3
np.full((2, 2), 7)       # все 7
np.eye(3)                # единичная матрица
np.arange(0, 10, 2)      # [0 2 4 6 8]
np.linspace(0, 1, 5)     # 5 чисел от 0 до 1
np.random.rand(3, 3)     # [0,1) случайные
np.random.randint(0, 10, (2, 3))  # целые
```

### Свойства массива
```python
a = np.array([[1, 2, 3], [4, 5, 6]])
a.shape         # (2, 3) — строки, столбцы
a.ndim          # 2 — размерность
a.size          # 6 — всего элементов
a.dtype         # int64 — тип
a.itemsize      # 8 — байт на элемент
a.nbytes        # 48 — всего байт
a.T             # транспонированная
```

### Операции по осям (axis)
```python
m = np.array([[1, 2], [3, 4]])
m.sum()              # 10 — сумма всех
m.sum(axis=0)        # [4 6] — сумма по столбцам
m.sum(axis=1)        # [3 7] — сумма по строкам
m.mean(axis=0)       # [2. 3.]
```

### Boolean indexing (маски)
```python
a = np.array([1, 5, 3, 8, 2])
a[a > 3]             # [5 8]
a[(a > 2) & (a < 6)] # [5 3]
a[a % 2 == 0]        # [8 2]
a[a > 3] = 0         # заменить все > 3 на 0
```

### Broadcasting (авто-расширение)
```python
a = np.array([1, 2, 3])
a + 10               # [11 12 13] — прибавили ко всем

m = np.array([[1, 2], [3, 4]])
m + np.array([10, 20])  # прибавили к каждому столбцу
```

**Правило:** если размеры совместимы (один из них 1), numpy автоматически расширит.

### Изменение формы
```python
a = np.arange(12)
a.reshape(3, 4)      # 3x4
a.reshape(4, -1)     # -1 = авто (4x3)
a.flatten()          # копия в 1D
a.ravel()            # view в 1D (быстрее)
```

### Объединение
```python
np.concatenate([a, b])      # склеить
np.vstack([a, b])           # вертикально
np.hstack([a, b])           # горизонтально
np.stack([a, b])            # новая ось
np.split(a, 3)              # разбить на 3 части
```

### Линейная алгебра
```python
np.linalg.inv(A)            # обратная матрица
np.linalg.det(A)            # определитель
np.linalg.eig(A)            # собственные значения
np.linalg.solve(A, b)       # решить Ax = b
A @ B                       # матричное умножение
A * B                       # поэлементное (не путать!)
```

### Сохранение и загрузка
```python
np.save('file.npy', a)
np.load('file.npy')
np.savez('file.npz', x=a, y=b)  # несколько массивов
np.savetxt('file.csv', a, delimiter=',')
np.loadtxt('file.csv', delimiter=',')
```

## ⚠️ Типичные ошибки

```python
# ❌ Смешивание numpy и списков
lst = [1, 2, 3]
lst * 2  # [1, 2, 3, 1, 2, 3] — повтор, не умножение

arr = np.array([1, 2, 3])
arr * 2  # [2 4 6] — умножение ✅

# ❌ Изменение формы у чужого массива
a = np.array([1, 2, 3, 4])
a.reshape(2, 2)  # ⚠️ Работает, но если a не contiguous — скопирует

# ❌ Сравнение массивов через == (даст массив)
a == 3  # [False, False, True, False]
np.any(a == 3)  # True — есть ли хоть один
np.all(a == 3)  # False — все ли равны

# ❌ Забыли копию — меняем оригинал
b = a  # это ссылка, не копия
b[0] = 100  # поменяет и a
b = a.copy()  # ✅ настоящая копия
```
