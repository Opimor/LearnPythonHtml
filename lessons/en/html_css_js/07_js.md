# 7. JavaScript — Complete Reference

JavaScript makes the page **alive**: reacts to clicks, changes text without reload, sends requests to the server.

## Variables

**`let`** — mutable (can be reassigned).
**`const`** — constant (cannot be reassigned).

```javascript
let age = 20;
age = 21;          // OK

const PI = 3.14;
// PI = 3;         // ERROR
```

## Data types

| Type | Example |
|---|---|
| Number | `42`, `3.14` |
| String | `'hello'`, "world" |
| Boolean | `true`, `false` |
| Array | `[1, 2, 3]` |
| Object | `{ name: 'Anna', age: 20 }` |
| null | `null` (empty) |
| undefined | `undefined` (not set) |

## Operators

```javascript
10 + 3;      // 13
10 - 3;      // 7
10 * 3;      // 30
10 / 3;      // 3.333...
10 % 3;      // 1 (remainder)
2 ** 10;     // 1024

'5' == 5;    // true (loose equality)
'5' === 5;   // false (strict equality)
```

## Conditions

```javascript
let age = 18;
if (age >= 18) {
  console.log('Adult');
} else {
  console.log('Child');
}
```

## Loops

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}
```

## Functions

```javascript
function add(a, b) {
  return a + b;
}
console.log(add(2, 3));  // 5

// Arrow function
const add2 = (a, b) => a + b;
```

## Arrays

| Method | What |
|---|---|
| `.push()` | Add to end |
| `.pop()` | Remove from end |
| `.map()` | Transform each item |
| `.filter()` | Keep only matching |
| `.reduce()` | Collapse to one value |
| `.forEach()` | Iterate |

```javascript
const nums = [1, 2, 3, 4];
nums.map(x => x * 2);          // [2, 4, 6, 8]
nums.filter(x => x % 2 === 0); // [2, 4]
nums.reduce((s, x) => s + x, 0); // 10
```

## DOM (working with the page)

```javascript
const btn = document.querySelector('.btn');
btn.textContent = 'New text';
btn.style.color = 'red';
btn.classList.add('active');

btn.addEventListener('click', () => {
  alert('Clicked!');
});
```

## Forms

```javascript
const input = document.querySelector('#name');

```

## localStorage

```javascript
localStorage.setItem('theme', 'dark');
```

## fetch — HTTP requests

```javascript
fetch('https://api.github.com/users/octocat')
  .then(r => r.json())
  .then(data => console.log(data.name));
```

## Common beginner mistakes

```javascript
// 1. == vs ===
console.log('5' == 5);    // true (coerces types)
console.log('5' === 5);   // false (strict, correct!)

// 2. Forgot let or const
let x = 10;  // correct

// 3. Arrow functions and this
const obj = {
  name: 'Anna',
  greet() { console.log(this.name); },  // 'Anna'
  greetArrow: () => { /* this.name is undefined */ }
};
```

## 📌 Remember

### Variables and types
| What | How |
|---|---|
| Mutable | `let x = 5;` |
| Constant | `const PI = 3.14;` |
| Number | `42`, `3.14` |
| String | `'hi'`, "`template ${x}`" |
| Boolean | `true` / `false` |
| Array | `[1, 2, 3]` |
| Object | `{ name: 'Anna', age: 20 }` |

### DOM
| What | How |
|---|---|
| Find element | `document.querySelector('.btn')` |
| Find all | `document.querySelectorAll('li')` |
| Change text | `el.textContent = 'new'` |
| Change style | `el.style.color = 'red'` |
| Add class | `el.classList.add('active')` |
| Create element | `document.createElement('div')` |
| Insert | `parent.appendChild(child)` |
| Remove | `el.remove()` |

### Events
| What | How |
|---|---|
| Click | `el.addEventListener('click', fn)` |
| Input | `el.addEventListener('input', fn)` |
| Form submit | `form.addEventListener('submit', fn)` |
| Prevent default | `event.preventDefault()` |

> 💡 **`===` vs `==`:** always use `===` (compares type and value). `==` coerces types and behaves strangely.
