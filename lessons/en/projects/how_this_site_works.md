# Project: How This Site Was Made

This site was fully generated by **DeepSeek AI** in chat: code, lessons, design, templates, guides. Below is a quick architectural breakdown so you understand how the app works.

## Stack

- **Python 3.13**
- **Flask** — web framework
- **Markdown** — turns `.md` lessons into HTML
- **Jinja2** — templates

- **Local SVG icons** + **Medeo font** — offline-friendly

## How the server works (app.py)

```python
from flask import Flask, render_template, request, jsonify, abort
import os, sys, subprocess
import markdown
from quizzes import get_quiz_for

app = Flask(__name__)
BASE = os.path.dirname(os.path.abspath(__file__))
LESSONS_DIR = os.path.join(BASE, 'lessons')

@app.route('/')
def index():
    return render_template('index.html', sections=list_lessons())

@app.route('/lesson/<section>/<slug>')
def lesson(section, slug):
    path = os.path.join(LESSONS_DIR, section, slug + '.md')
    md = open(path, encoding='utf-8').read()
    html = markdown.markdown(md, extensions=['fenced_code', 'tables'])
    quiz = get_quiz_for(slug) if section == 'basics' else None
    return render_template('lesson.html', content=html, quiz=quiz)
```

Main ideas:
- **list_lessons()** walks the `lessons/` folder automatically
- **markdown.markdown()** converts `.md` to HTML
- **render_template()** serves a template with data

## Playground (running code)

```python
@app.route('/run', methods=['POST'])
def run():
    code = request.json.get('code')
    result = subprocess.run(
        [sys.executable, '-c', code],
        capture_output=True, text=True, timeout=10
    )
    return jsonify({'stdout': result.stdout, 'stderr': result.stderr})
```

Code runs in a **separate process** via `subprocess` with a 10-second timeout.

## Quizzes (quizzes.py)

When you click 'I studied — take the quiz':
1. Lesson text is hidden (`display: none`)
2. Questions are shown (JS + `quizzes.py`)
3. Answers are sent to `/check_quiz/<slug>`
4. Server compares and returns the result
5. On success — `localStorage.setItem('passed_<slug>', '1')`

## How to add a lesson

1. Create `.md` in `lessons/basics/` or `lessons/libraries/`.
2. First line `# Title` becomes the menu name.
3. Code in fenced blocks.
4. No restart needed.
