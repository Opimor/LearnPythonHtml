# Практикум: Змейка на pygame

Не даю готовый код — вот **задание** и подсказки. Код пиши ты.

## 🎯 Цель

Игра «Змейка»: ползёт по полю, ест яблоки, растёт. Врезался в стену или в себя — Game Over.

## 🧩 Что понадобится

| Технология | Где учил |
|---|---|
| `pygame.init()`, `set_mode()` | pygame гайд |
| Главный цикл `while running:` | pygame гайд |
| Списки (для тела змейки) | Урок 5 |
| `random.randint()` | Урок 11 / stdlib |

## 📋 План по шагам

### Шаг 1. Окно и цвета

Подключи pygame, создай окно 600×600. Заведи переменные для цветов:
```python
import pygame
import random
import sys

pygame.init()
WIDTH, HEIGHT = 600, 600
CELL = 20
screen = pygame.display.set_mode((WIDTH, HEIGHT))
clock = pygame.time.Clock()
```

### Шаг 2. Змейка как список

Змейка — это список координат клеток. Первая — голова. Начни с трёх клеток:
```python
snake = [(10, 10), (9, 10), (8, 10)]  # голова в (10,10)
direction = (1, 0)  # движется вправо: (dx, dy)
```

**Почему список?** — потому что змейка растёт: когда съедает яблоко, добавляем новую голову в начало и НЕ удаляем хвост.

### Шаг 3. Яблоко

Случайная клетка:
```python
food = (random.randint(0, WIDTH // CELL - 1), random.randint(0, HEIGHT // CELL - 1))
```

### Шаг 4. Главный цикл — обработка клавиш

Внутри `while running:` лови события. При нажатии стрелок меняй `direction`. **Нельзя** повернуть в противоположную сторону (иначе змейка съест себя).

Подсказка: `if event.key == pygame.K_UP and direction != (0, 1): direction = (0, -1)`.

### Шаг 5. Движение

Каждый кадр:
1. Возьми голову: `head_x, head_y = snake[0]`
2. Прибавь направление: `new_head = (head_x + direction[0], head_y + direction[1])`
3. **Проверь**, не вышла ли за стены: `if not (0 <= new_head[0] < WIDTH // CELL and ...): game_over()`
4. **Проверь**, не укусила ли себя: `if new_head in snake: game_over()`
5. Вставь новую голову: `snake.insert(0, new_head)`
6. Если голова на яблоке — генерируй новое яблоко, увеличь счёт. Иначе — `snake.pop()` (убери хвост).

### Шаг 6. Отрисовка

Каждый кадр:
1. `screen.fill((20, 20, 30))` — фон
2. Нарисуй змейку циклом: для каждой (x, y) нарисуй прямоугольник `pygame.draw.rect(screen, color, (x*CELL, y*CELL, CELL-2, CELL-2))`
3. Голову сделай другим цветом (например, ярче)
4. Нарисуй яблоко
5. Выведи счёт (через `font.render`)
6. `pygame.display.flip()` и `clock.tick(10)`

### Шаг 7. Game Over

Функция `game_over()`, которая показывает «Game Over» на экране, ждёт 2 секунды (`pygame.time.wait(2000)`) и делает `pygame.quit(); sys.exit()`.

## ✅ Проверка

| Что проверить | Как |
|---|---|
| Окно открывается | Скрипт запускается, окно 600×600 |
| Змейка ползёт | Сразу после запуска движется вправо |
| Стрелки работают | Нажатия меняют направление |
| Нельзя развернуться | Нажал влево при движении вправо — не сработало |
| Яблоко съедается | Змейка растёт, счёт +1 |
| Стены убивают | Врезалась в край — Game Over |
| Себя убивает | Укусила себя — Game Over |

## 🚀 Задания на доработку

1. **Ускорение** — каждое съеденное яблоко уменьшает задержку `clock.tick()` на 1 (минимум 20).
2. **Стены** — нарисуй стены по краям (прямоугольники), змейка умрёт при касании.
3. **Свои цвета** — измени палитру.
4. **Звук** — добавь `pygame.mixer.Sound` при съедании яблока.

> 💡 **Совет:** если что-то не работает, выводи в консоль через `print()` значения переменных. Например, `print(new_head, snake)` — увидишь, куда двигается голова.
