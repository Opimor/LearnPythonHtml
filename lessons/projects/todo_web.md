## 📋 План работы (делай по шагам)

### Шаг 1. HTML — каркас

Создай файл `index.html`. Тебе нужно:
1. `<!DOCTYPE html>`, `<html>`, `<head>` с `<meta charset>`, `<title>`
2. Подключить `<link rel=" + Q + "stylesheet" + Q + " href=" + Q + "style.css" + Q + ">` в `<head>`
3. В `<body>`: заголовок `<h1>`, поле `<input>` с `id`, кнопка `<button>` с `id`, пустой `<ul>` с `id`
4. Подключить `<script src=" + Q + "script.js" + Q + "></script>` в конце `<body>`

**Подсказка:** `id` — это уникальные имена, чтобы потом найти элементы через JS. Например: `taskInput`, `addBtn`, `taskList`.

### Шаг 2. CSS — оформление

Создай `style.css`. Сделай так, чтобы:
1. Всё было по центру: `body { display: flex; align-items: center; justify-content: center; min-height: 100vh; }`
2. У формы был белый фон, скругление (`border-radius`) и тень (`box-shadow`)
3. У поля и кнопки был `padding` (например, `12px`)
4. Кнопка «Добавить» — синяя, при наведении становится темнее (через `:hover`)
5. У задач (`<li>`) был `display: flex` и `justify-content: space-between` (текст слева, кнопка справа)

### Шаг 3. JS — добавление задачи

Создай `script.js`. Логика такая:

```
1. Найди через querySelector три элемента: input, button, list
2. Создай пустой массив tasks = []
3. При клике на кнопку:
   - прочитай текст из input (input.value)
   - если пусто — не делай ничего
   - добавь текст в массив tasks
   - очисти поле (input.value = '')
   - перерисуй список
```

**Подсказка:** добавь обработчик так:
```javascript
const input = document.querySelector('#taskInput');
const addBtn = document.querySelector('#addBtn');
const list = document.querySelector('#taskList');
let tasks = [];

addBtn.addEventListener('click', () => {
    // твой код здесь
});
```

### Шаг 4. JS — функция renderTasks()

Это функция, которая **рисует задачи из массива на странице**. Вызывай её после каждого изменения массива.

Что делать внутри:
1. Очисти список: `list.innerHTML = ''`
2. Пройди циклом по массиву `tasks`
3. Для каждой задачи создай `<li>` и `<button>` внутри
4. Кнопке «Удалить» привяжи обработчик: удалить задачу из массива и перерисовать
5. Добавь `<li>` в `list` через `list.appendChild(li)`

**Подсказка:** удаление по индексу — `tasks.splice(index, 1)`. Для этого тебе нужен `index` в цикле (используй `forEach((task, index) => ...)`).

### Шаг 5. JS — сохранение в localStorage

Чтобы задачи не пропадали:
1. В конце `renderTasks` или после каждого изменения сохраняй массив:
   `localStorage.setItem('tasks', JSON.stringify(tasks))`
2. При загрузке страницы (в самом низу файла) читай массив обратно:
   `tasks = JSON.parse(localStorage.getItem('tasks')) || []`
3. Сразу вызови `renderTasks()`, чтобы показать сохранённые задачи.

**Почему `JSON.stringify`?** — localStorage хранит только строки. Объекты нужно превращать в JSON.

## 🚀 Задания на доработку (чтобы закрепить)

1. **Enter добавляет задачу** — добавь обработчик `keypress` на input, проверь `event.key === 'Enter'`.
2. **Зачёркивание выполненных** — при клике на саму задачу (не кнопку) зачёркивай текст через `text-decoration: line-through`.
3. **Счётчик** — выводи под списком «Всего задач: N», обновляй при каждом изменении.
4. **Своя тема** — поменяй цвета, шрифты. Сделай так, чтобы выглядело так, как нравится тебе.

## 🤔 Если застрял

1. Открой консоль браузера (F12 → Console) — там будут ошибки.
2. Прочитай сообщение: `Uncaught TypeError: Cannot read property 'value' of null` — значит, `querySelector` вернул `null`. Проверь, что `id` в HTML и в JS совпадают.
3. Если логика не работает — расставь `console.log()` после каждой строки, чтобы понять, где сломалось.
