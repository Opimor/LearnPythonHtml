## 🎯 Цель

Десктопное приложение: вводишь город, нажимаешь кнопку — видишь погоду (температура, описание, влажность).

## 🧩 Что понадобится

| Технология | Зачем | Где учил |
|---|---|---|
| `tkinter` | окно, поле, кнопка | гайд tkinter |
| `requests` | запрос к API | гайд requests |
| JSON | разбор ответа | Урок 6 |
| `try / except` | обработка ошибок | Урок 10 |

## 📋 Подготовка

1. Установи `requests`: `pip install requests`
2. Зарегистрируйся на [openweathermap.org](https://openweathermap.org/api) и получи **бесплатный API-ключ** (приходит на почту за 5 минут).

## 📋 План по шагам

### Шаг 1. Окно

Создай `weather.py`. Сделай окно 400×400 с заголовком «Погода». Внутри:
1. `Label` с текстом «Погода в городе»
2. `Entry` — поле для ввода города
3. `Button` с текстом «Узнать погоду» и `command=функция`
4. Ещё один `Label` — для вывода результата

**Подсказка:** `root = tk.Tk()` → `root.geometry('400x400')` → элементы через `.pack()` или `.grid()` → `root.mainloop()`.

### Шаг 2. Функция get_weather()

Это функция, которая вызывается при клике на кнопку. Внутри:
1. Прочитай город: `city = entry.get().strip()`
2. Если пусто — покажи `messagebox.showwarning('Ошибка', 'Введи город')` и `return`
3. Сделай запрос к API.

**Как выглядит запрос:**
```python
url = 'https://api.openweathermap.org/data/2.5/weather'
params = {
    'q': city,
    'appid': 'ТВОЙ_КЛЮЧ_СЮДА',
    'units': 'metric',
    'lang': 'ru',
}
```

Параметры:
- `q` — название города
- `appid` — твой API-ключ
- `units: metric` — температура в °C (не в °F)
- `lang: ru` — описание на русском

**Подсказка:** оберни запрос в `try / except requests.Timeout` — сервер может не ответить.

### Шаг 3. Разбор JSON

Если `response.status_code == 200`, в `response.json()` придет словарь. Вытащи:
- Температура: `data['main']['temp']`
- Ощущается: `data['main']['feels_like']`
- Влажность: `data['main']['humidity']`
- Описание: `data['weather'][0]['description']`

Если статус **не** 200 — покажи «Город не найден» в `result_label`.

### Шаг 4. Показ результата

Формируй f-строку и передавай в `result_label.config(text=...)`:
```python
result_label.config(text=f'{city}\n{desc.capitalize()}\n{temp:.1f}°C\nВлажность: {hum}%')
```

## ✅ Проверка

| Что проверить | Как |
|---|---|
| Окно открывается | Скрипт запускается, окно 400×400 |
| Пустой ввод | Кнопка с пустым полем — предупреждение |
| Верный город | Вводишь «Москва» — температура и описание |
| Неверный город | Вводишь «абракадабра» — сообщение «Не найден» |
| Сеть отключена | Отключи интернет, нажми кнопку — сообщение об ошибке |

## 🚀 Задания на доработку

1. **Enter запускает поиск** — привяжи `<Return>` к полю, чтобы Enter вызывал `get_weather()`.
2. **Иконка погоды** — загрузи картинку через `PhotoImage` в `Label`.
3. **Сохранение последнего города** — записывай в файл `last_city.txt`, при запуске подставляй обратно.
4. **Прогноз на 5 дней** — используй эндпоинт `/forecast` (тоже бесплатный).

> 💡 **Главное:** API — это просто URL + параметры. Не бойся `print(response.json())` — так ты увидишь всю структуру ответа и поймёшь, откуда брать поля.
