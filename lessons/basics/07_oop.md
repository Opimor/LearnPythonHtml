# 7. ООП — классы и объекты (простыми словами)

## Что такое ООП?
ООП (Объектно-Ориентированное Программирование) — это способ писать код, где мы создаём **свои типы данных**.

Представь, что ты делаешь игру. У тебя есть 100 врагов. Если ты будешь описывать каждого врага отдельно (здоровье, скорость, атака), ты сойдёшь с ума. ООП позволяет создать **Чертеж** (класс) один раз, а потом по нему создавать **Объекты** (врагов).

## Класс и объект
**Класс** — это чертёж (шаблон).
**Объект** — это то, что сделано по чертежу (конкретный враг).

**`class`** — эта команда создаёт новый чертёж (класс). Пример:
```python
class Dog:
    pass  # пока пустой

# Создаём объект (конкретную собаку) по чертежу
my_dog = Dog()
```

## `__init__` — конструктор (рождение объекта)
Когда объект создаётся, нужно сразу дать ему имя и возраст. Для этого есть специальная функция `__init__` (два подчёркивания с каждой стороны).

**`__init__`** — этот метод срабатывает автоматически в момент создания объекта. **`self`** — это ссылка на самого себя (конкретную собаку). Пример:
```python
class Dog:
    def __init__(self, name, age):
        self.name = name  # сохраняем имя внутри собаки
        self.age = age    # сохраняем возраст

my_dog = Dog('Рекс', 3)
print(my_dog.name)  # 'Рекс'
```

## Методы — что умеет объект
**Метод** — это функция, которая находится внутри класса. Она описывает, что объект умеет делать.

**`def bark(self):`** — этот метод описывает действие (лай). Пример:
```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        return f'{self.name} говорит: Гав!'

my_dog = Dog('Рекс')
print(my_dog.bark())  # 'Рекс говорит: Гав!'
```

## Наследование — когда объект становится «сыном» другого
Представь, что у нас есть класс `Animal` (животное). Собака — это тоже животное. Мы можем сделать так, чтобы `Dog` получил все свойства `Animal`.

**`class Dog(Animal):`** — эта запись означает «класс Dog наследует всё от класса Animal». Пример:
```python
class Animal:
    def speak(self):
        return '...'

class Dog(Animal):  # Собака наследует всё от Animal
    def speak(self):  # Но говорит по-своему
        return 'Гав!'

my_dog = Dog()
print(my_dog.speak())  # 'Гав!'
```

## Типичные ошибки
```python
# 1. Забыли self в аргументах метода
class Bad:
    def bark():  # НЕТ self! Будет ошибка при вызове
        pass
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Создать класс | `class Имя:` |
| Конструктор | `def __init__(self, ...):` |
| Метод | `def метод(self):` |
| Создать объект | `obj = Класс(параметры)` |
| Наследование | `class Дочерний(Родитель):` |
| Вызвать родителя | `super().__init__(...)` |
| Свойство | `@property` |

> 💡 **Главная мысль:** Классы нужны, когда у тебя много похожих объектов (враги, пользователи, товары). Если функция простая — обычная функция лучше.
