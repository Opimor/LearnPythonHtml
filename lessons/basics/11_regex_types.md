# 11. Регулярки и типизация

## Регулярные выражения (regex)
Регулярки — это шаблоны для поиска текста. Представь, что ты ищешь не просто слово «кот», а «любое трехбуквенное слово».

**`re.findall()`** — находит ВСЕ совпадения и возвращает их списком.

```python
import re
text = 'Мне 20 лет, а тебе 25'
print(re.findall(r'\d+', text))  # ['20', '25'] — ищет все цифры
```

**`re.sub()`** — заменяет найденные совпадения на что-то другое.

```python
print(re.sub(r'\d+', 'X', text))  # 'Мне X лет, а тебе X'
```

| Символ | Что значит |
|---|---|
| `\d` | Любая цифра (0-9) |
| `\w` | Любая буква или цифра |
| `+` | Один или больше |
| `*` | Ноль или больше |
| `.` | Любой символ |

## Аннотации типов (типизация)
Python не требует указывать типы, но это помогает тебе и редактору кода не запутаться. Это как подсказки.

**`def name(arg: тип) -> тип:`** — так указывают, что функция принимает и что возвращает.

```python
def greet(name: str, age: int) -> str:
    return f'{name}, {age} лет'
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Найти все | `re.findall(r'\d+', text)` |
| Заменить | `re.sub(r'\d', 'X', text)` |
| Разбить | `re.split(r',', text)` |
| Цифра | `\d` |
| Буква/цифра | `\w` |
| Один или больше | `+` |
| Аннотация типа | `def f(x: int) -> str:` |

> 💡 Аннотации не проверяются при запуске, но если ты передашь не то, IDE подсветит ошибку.
