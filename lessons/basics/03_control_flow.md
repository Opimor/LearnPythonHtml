# 3. Условия и циклы

## Условия (`if`)
**`if`** (если) — проверяет условие. Если оно истинно (`True`), выполняется код под ним. Если ложно (`False`), Python его пропускает.

**Важно:** в Python отступы (обычно 4 пробела) показывают, какой код относится к `if`.

```python
age = 18
if age >= 18:
    print('Ты взрослый')  # Этот код выполнится, потому что 18 >= 18
```

## `else` и `elif`
- **`else`** (иначе) — выполняется, если условие в `if` не сработало.
- **`elif`** (иначе если) — проверяет следующее условие, если предыдущее провалилось.

```python
age = 15
if age >= 18:
    print('Взрослый')
elif age >= 14:
    print('Подросток')  # Сработает это
else:
    print('Ребёнок')
```

## Логические операторы
- **`and`** (И) — вернет True, если ОБА условия верны.
- **`or`** (ИЛИ) — вернет True, если ХОТЯ БЫ ОДНО условие верно.
- **`not`** (НЕ) — переворачивает значение (True становится False).

```python
x = 15
if x > 10 and x < 20:
    print('x между 10 и 20')
```

## Цикл `for` (для перебора)
**`for`** берет элементы из последовательности по одному и выполняет код для каждого.

**`range(5)`** — создает последовательность чисел от 0 до 4 (5 штук).

```python
for i in range(5):
    print(i)  # Выведет 0, 1, 2, 3, 4
```

Можно перебирать и элементы списка:
```python
fruits = ['яблоко', 'банан', 'груша']
for fruit in fruits:
    print(fruit)
```

## Цикл `while` (пока условие верно)
**`while`** повторяет код, пока условие остается истинным. Главное — не забыть изменить переменную внутри, чтобы цикл не стал бесконечным!

```python
n = 3
while n > 0:
    print(n)
    n -= 1  # Уменьшаем n, иначе будет бесконечно печатать 3
```

## Прерывание цикла
- **`break`** — полностью выходит из цикла.
- **`continue`** — пропускает текущий шаг и переходит к следующему.

```python
for i in range(10):
    if i == 5:
        break  # Как только i станет 5, цикл остановится
    print(i)   # Выведет 0, 1, 2, 3, 4
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Если | `if условие:` |
| Иначе если | `elif условие:` |
| Иначе | `else:` |
| И / ИЛИ / НЕ | `and` / `or` / `not` |
| Цикл по числам | `for i in range(5):` |
| Цикл пока | `while условие:` |
| Выйти из цикла | `break` |
| Пропустить шаг | `continue` |
| Отступы | 4 пробела обязательны |

> 💡 **Совет:** если сомневаешься, сработает условие или нет, выведи его через `print(x > 10)`. Python покажет `True` или `False`.
