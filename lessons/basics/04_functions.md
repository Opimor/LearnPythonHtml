# 4. Функции — простыми словами

## Что такое функция?
Функция — это кусок кода, которому дали имя. Его можно вызывать много раз, не переписывая заново. Это как рецепт: один раз записал, а готовишь по нему сколько хочешь.

## Создание и вызов
**`def`** (от define — определить) — команда, которая создаёт функцию. После `def` пишется имя функции, скобки и двоеточие.

```python
def greet():
    print('Привет!')

greet()  # Вызов функции (без def)
greet()  # Можно вызывать много раз
```

## Параметры и аргументы
В скобках можно указать **параметры** — переменные, которые функция принимает при вызове.

```python
def greet(name):  # name — параметр
    print(f'Привет, {name}!')

greet('Аня')    # 'Аня' — аргумент
greet('Иван')
```

## Возврат значения (`return`)
**`return`** — команда, которая возвращает результат из функции. Без неё функция возвращает `None` (пустоту).

```python
def add(a, b):
    return a + b  # вернёт сумму

result = add(2, 3)
print(result)  # 5
```

## Параметры по умолчанию
Можно задать значение, которое используется, если аргумент не передан.

```python
def greet(name='Гость'):
    print(f'Привет, {name}!')

greet()        # Привет, Гость!
greet('Аня')   # Привет, Аня!
```

## Именованные аргументы
Аргументы можно передавать по имени, тогда порядок не важен.

```python
def user_info(name, age):
    print(f'{name}, {age} лет')

user_info(age=20, name='Аня')  # Аня, 20 лет
```

## *args и **kwargs (для любого числа аргументов)
- **`*args`** — собирает все позиционные аргументы в кортеж.
- **`**kwargs`** — собирает все именованные аргументы в словарь.

```python
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3))  # 6
```

## Лямбда-функции (короткие функции)
**`lambda`** — создаёт функцию в одну строку. Часто используется для сортировки.

```python
square = lambda x: x ** 2
print(square(5))  # 25
```

## Рекурсия (функция вызывает саму себя)
```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Создать функцию | `def имя(параметры):` |
| Вернуть значение | `return результат` |
| Параметр по умолчанию | `def f(x=5):` |
| Любое число аргументов | `def f(*args):` |
| Именованные аргументы | `def f(**kwargs):` |
| Короткая функция | `lambda x: x**2` |
| Вызвать | `имя(аргументы)` |

> 💡 **Правило:** если код повторяется больше 2 раз — вынеси его в функцию.
