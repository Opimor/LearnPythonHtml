# 1. Введение в Python

Python — это язык программирования. На нём пишут сайты, игры, нейросети и скрипты для автоматизации.

## Первая программа
**`print()`** — это функция, которая выводит текст на экран (в консоль). Внутри скобок пишется то, что нужно вывести. Текст обязательно берётся в кавычки.

```python
print('Hello, World!')
print('Привет, мир!')
print(2 + 2)  # Можно выводить и математику
```

## Комментарии
**Комментарии** — это текст, который Python игнорирует. Они нужны, чтобы человек (ты) понимал, что делает код.
**`#`** — символ, с которого начинается комментарий (до конца строки).

```python
# Это однострочный комментарий
x = 5  # Комментарий можно писать и после кода
```

## Как запускать код
1. **В файле** — создай файл `hello.py`, напиши код, запусти в терминале: `python hello.py`.
2. **В терминале** — просто введи `python` и пиши код построчно.
3. **В песочнице** на этом сайте — вкладка «Песочница», пиши и жми «Запустить».

## Типы данных
У каждого значения в Python есть тип. Вот основные:

| Тип | Пример | Что это |
|---|---|---|
| `int` | `42` | Целое число |
| `float` | `3.14` | Дробное число |
| `str` | `"привет"` | Строка (текст) |
| `bool` | `True` / `False` | Логический (истина/ложь) |
| `list` | `[1, 2, 3]` | Список |
| `tuple` | `(1, 2, 3)` | Кортеж (неизменяемый список) |
| `dict` | `{"a": 1}` | Словарь (ключ: значение) |
| `set` | `{1, 2, 3}` | Множество (уникальные элементы) |

**`type()`** — функция, которая показывает тип значения. Пример:
```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type('Привет')) # <class 'str'>
```

## Ввод данных от пользователя
**`input()`** — функция, которая ждёт, пока пользователь что-то введёт, и возвращает это как **строку** (текст).

```python
name = input('Как тебя зовут? ')
print(f'Привет, {name}!')

age = int(input('Сколько тебе лет? '))  # int() превращает текст в число
print(f'Через год тебе будет {age + 1}')
```

## Типичные ошибки новичка
```python
# 1. Забыли кавычки у строки
# print(Hello)  → NameError
print('Hello')   # правильно

# 2. Перепутали print и input
# name = print('Имя:')  → name = None
name = input('Имя: ')
```

## 📌 Запомни главное

| Что | Как | Пример |
|---|---|---|
| Вывести текст | `print()` | `print('Привет')` |
| Спросить у пользователя | `input()` | `name = input('Имя? ')` |
| Комментарий | `# текст` | `# это комментарий` |
| Узнать тип | `type(x)` | `type(42)` → `int` |
| Типы | `int`, `float`, `str`, `bool` | `42`, `3.14`, `'hi'`, `True` |

> 💡 **Совет:** не бойся ошибок — читай сообщение. Python пишет, в какой строке проблема и что не так.
