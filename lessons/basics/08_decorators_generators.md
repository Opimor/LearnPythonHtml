# 8. Декораторы — «обёртки» для функций

## Что такое декоратор? (Пример из жизни)
Представь, что у тебя есть функция `купить_хлеб()`. Ты хочешь, чтобы каждый раз, когда она вызывается, в консоль печаталось «Начинаю выполнение» и «Закончил».

Ты можешь вставить `print()` внутрь функции, но если у тебя 100 функций, это неудобно. Декоратор позволяет **обернуть** функцию, как подарочную коробку, и добавить поведение снаружи.

## Как написать декоратор
**Декоратор** — это функция, которая принимает другую функцию и возвращает новую (обёрнутую).

**`@my_decorator`** — этот символ ставится над функцией, чтобы применить к ней декоратор. Пример:
```python
def my_decorator(func):
    def wrapper():
        print('--- Начало ---')
        func()  # вызываем оригинальную функцию
        print('--- Конец ---')
    return wrapper

@my_decorator
def say_hello():
    print('Привет!')

say_hello()
```

## Генераторы — ленивые списки
Представь, что тебе нужно перебрать 10 миллионов чисел. Если ты создашь список из 10 миллионов, компьютер съест всю память.

**Генератор** — это функция, которая выдаёт значения по одному, когда её об этом просят. Она не хранит их все в памяти.

**`yield`** — эта команда возвращает значение и «засыпает» до следующего запроса. Пример:
```python
def countdown(n):
    while n > 0:
        yield n  # отдаём число и ждём следующего
        n -= 1

for num in countdown(3):
    print(num)  # 3, 2, 1
```

**`next()`** — эта функция вручную запрашивает следующее значение у генератора. Пример:
```python
gen = countdown(5)
print(next(gen))  # 5
print(next(gen))  # 4
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Декоратор | `@имя_декоратора` над функцией |
| Генератор | функция с `yield` внутри |
| Получить значение | `next(gen)` |
| Генераторное выражение | `(x for x in range(5))` |
| Список через генератор | `[x for x in range(5)]` |
| Когда использовать | Экономия памяти для больших данных |

> 💡 **Главное:** декораторы добавляют поведение, не меняя код функции. Генераторы экономят память.
