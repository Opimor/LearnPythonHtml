# 2. Переменные и типы данных

## Что такое переменная?
Представь, что переменная — это коробка с наклейкой (именем). Внутрь ты можешь положить число, текст или что-то другое. Потом ты можешь достать это значение по имени коробки.

**`=`** (один знак равно) — это команда присваивания. Она кладет значение в переменную. (Не путай с `==`, которое проверяет равенство).

```python
age = 25          # Создаем переменную age и кладем туда число 25
name = 'Иван'     # Создаем name и кладем текст
print(age)        # Достаем значение из коробки age
```

## Правила именования
- Имя может состоять из букв, цифр и `_` (нижнее подчеркивание).
- Имя не может начинаться с цифры.
- Python различает регистр: `age` и `Age` — это разные переменные.
- Нельзя использовать зарезервированные слова (`if`, `for`, `class` и т.д.).

## Основные типы данных
**Тип** — это то, что лежит в коробке (число, текст, правда/ложь).

| Тип | Название | Пример |
|---|---|---|
| `int` | Целое число | `42`, `-10`, `0` |
| `float` | Дробное число | `3.14`, `0.5` |
| `str` | Строка (текст) | `'Привет'`, `"Python"` |
| `bool` | Логический | `True` (истина), `False` (ложь) |

**`type()`** — эта функция показывает, какой тип данных лежит в переменной.
```python
print(type(42))       # <class 'int'>
print(type('Привет')) # <class 'str'>
```

## Приведение типов (превращение)
Иногда нужно превратить текст в число или наоборот.
- **`int()`** — превращает в целое число.
- **`float()`** — превращает в дробное.
- **`str()`** — превращает в текст.

```python
x = '42'          # Это текст
y = int(x)        # Теперь это число 42
print(y + 8)      # 50 (с текстом так не сложить)
```

## f-строки (самый удобный способ вывода)
**f-строка** — это строка с буквой `f` перед кавычками. Внутри неё можно вставлять переменные в фигурных скобках `{}`, и они сразу подставятся в текст.

```python
name = 'Аня'
age = 20
print(f'Привет, {name}! Тебе {age} лет.')
print(f'Через год тебе будет {age + 1}')  # Внутри скобок можно даже считать
```

## Арифметика
```python
print(10 + 3)   # 13 (сложение)
print(10 - 3)   # 7 (вычитание)
print(10 * 3)   # 30 (умножение)
print(10 / 3)   # 3.33 (деление, всегда дает float)
print(10 // 3)  # 3 (деление без остатка - отбрасывает дробную часть)
print(10 % 3)   # 1 (остаток от деления)
print(2 ** 3)   # 8 (возведение в степень, 2 в кубе)
```

## Строки (текст)
У текста есть встроенные команды (методы), которые с ним что-то делают.

```python
s = 'Python'
print(len(s))          # 6 (длина строки)
print(s.upper())       # PYTHON (все заглавные)
print(s.lower())       # python (все строчные)
print(s.replace('P', 'J'))  # Jython (заменить букву)
print(s[0])            # P (первая буква, индексы с 0)
print(s[0:3])          # Pyt (срез с 0 по 3, не включая 3)
```

## 📌 Запомни главное

| Что | Как | Пример |
|---|---|---|
| Создать переменную | `имя = значение` | `age = 25` |
| Вывести | `print(...)` | `print(age)` |
| Узнать тип | `type(x)` | `type(42)` → `int` |
| Превратить в число | `int()` / `float()` | `int('42')` |
| Форматировать текст | `f'...{x}...'` | `f'Мне {age}'` |
| Целочисленное деление | `//` | `10 // 3` → `3` |
| Остаток | `%` | `10 % 3` → `1` |
| Степень | `**` | `2 ** 3` → `8` |
