# 13. Git и GitHub

## Что такое Git?
Git — это система контроля версий. Она запоминает состояние кода в любой момент (как сохранения в игре).

**`git init`** — создаёт новый репозиторий (папку `.git`) в текущем проекте.

```bash
git init
```

**`git add .`** — добавляет все измененные файлы в список для следующего сохранения.

```bash
git add .
```

**`git commit -m 'сообщение'`** — фиксирует (сохраняет) изменения с комментарием.

```bash
git commit -m 'Первый коммит'
```

## GitHub
GitHub — это облачный сайт для хранения таких репозиториев.

**`git push`** — отправляет твои сохранения (коммиты) на GitHub.

```bash
git push origin main
```

**`git pull`** — скачивает изменения с GitHub на твой компьютер (если кто-то другой их туда залил).

```bash
git pull
```

## 📌 Запомни главное

| Что | Команда |
|---|---|
| Создать репозиторий | `git init` |
| Добавить файлы | `git add .` |
| Сохранить | `git commit -m 'сообщение'` |
| Отправить на GitHub | `git push origin main` |
| Скачать изменения | `git pull` |
| История | `git log --oneline` |
| Отменить изменения | `git restore файл` |
