# 5. Списки, кортежи, словари, множества

## Списки (`list`) — самый важный тип
Список — это упорядоченная коллекция элементов в квадратных скобках `[]`. Может хранить что угодно и меняться.

```python
fruits = ['яблоко', 'банан', 'груша']
numbers = [1, 2, 3, 4, 5]
mixed = [1, 'два', 3.0, True]  # можно смешивать типы
```

### Индексы (доступ по номеру)
Нумерация начинается с **0**. Первый элемент — `[0]`, последний — `[-1]`.

```python
fruits = ['яблоко', 'банан', 'груша']
print(fruits[0])   # яблоко
print(fruits[-1])  # груша
print(fruits[1:3]) # ['банан', 'груша'] (срез)
```

### Методы списков
- **`.append(x)`** — добавляет `x` в конец списка.
- **`.insert(i, x)`** — вставляет `x` на позицию `i`.
- **`.remove(x)`** — удаляет первый элемент со значением `x`.
- **`.pop()`** — удаляет и возвращает последний элемент (или `pop(i)` по индексу).
- **`.sort()`** — сортирует на месте.
- **`.reverse()`** — разворачивает на месте.

```python
fruits = ['яблоко', 'банан']
fruits.append('груша')  # ['яблоко', 'банан', 'груша']
fruits.remove('банан')  # ['яблоко', 'груша']
print(fruits)
```

### Длина и проверка
**`len()`** — длина списка. **`in`** — проверяет, есть ли элемент.

```python
print(len(fruits))         # 2
print('яблоко' in fruits)  # True
```

## Кортеж (`tuple`) — неизменяемый список
Кортеж похож на список, но его нельзя изменить после создания (в круглых скобках).

```python
point = (10, 20)
print(point[0])  # 10
# point[0] = 5   # ОШИБКА! Кортеж нельзя менять
```

## Словарь (`dict`) — пары ключ-значение
Словарь хранит данные в виде `ключ: значение` в фигурных скобках `{}`. Это как телефонная книга.

```python
user = {
    'name': 'Аня',
    'age': 20,
    'city': 'Москва'
}
print(user['name'])  # Аня
user['age'] = 21     # изменение
user['email'] = 'a@b.ru'  # добавление
del user['city']     # удаление
```

### Методы словаря
- **`.get(k)`** — безопасно получает значение (если ключа нет, вернет `None`, а не ошибку).
- **`.keys()`** — все ключи.
- **`.values()`** — все значения.
- **`.items()`** — пары `(ключ, значение)`.

```python
print(user.get('name'))     # Аня
print(user.get('unknown'))  # None
```

## Множество (`set`) — уникальные элементы
Множество хранит только уникальные элементы (без порядка) в фигурных скобках.

```python
a = {1, 2, 3, 3, 3}  # {1, 2, 3} (дубликаты удаляются)
b = {3, 4, 5}
print(a & b)  # {3} (пересечение)
print(a | b)  # {1, 2, 3, 4, 5} (объединение)
```

## 📌 Запомни главное

| Что | Как |
|---|---|
| Список | `[1, 2, 3]` |
| Кортеж (неизменяемый) | `(1, 2, 3)` |
| Словарь (ключ→значение) | `{'a': 1}` |
| Множество (уникальные) | `{1, 2, 3}` |
| Добавить в конец списка | `lst.append(x)` |
| Удалить по значению | `lst.remove(x)` |
| Длина | `len(lst)` |
| Взять по индексу | `lst[0]`, `lst[-1]` |
| Значение из словаря | `d['key']` или `d.get('key')` |
| Все пары словаря | `d.items()` |

> 💡 **Правило:** список — для упорядоченных данных, словарь — для данных с ключами, множество — для уникальности.
