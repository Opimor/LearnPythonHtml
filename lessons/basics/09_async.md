# 9. Асинхронность — как делать несколько дел сразу

## В чём проблема? (Обычный код)
Обычный код выполняется по очереди. Если ты скачиваешь файл из интернета, программа «замирает» и ждёт, пока файл не скачается. В это время она не может делать ничего другого.

Представь, что ты в Макдональдсе. Кассир принимает заказ, уходит на кухню, готовит бургер, возвращается и отдаёт его тебе. И только потом начинает принимать заказ у следующего человека. Это **синхронный** код.

## Как работает асинхронность? (async)
Асинхронность — это когда кассир принимает заказ, отдаёт его на кухню, и сразу начинает принимать заказ у следующего человека. Пока повара готовят бургеры, кассир не стоит без дела.

В Python для этого используются **`async`** и **`await`**.

**`async def`** — эта команда создаёт асинхронную функцию (как обычную, но она может «тормозить» и ждать, не блокируя всё остальное). Пример:
```python
import asyncio

async def make_burger():
    print('Начал готовить бургер...')
    await asyncio.sleep(2)  # await = ждём 2 секунды (типа готовим)
    print('Бургер готов!')
```

**`asyncio.run()`** — эта функция запускает асинхронный код. Пример:
```python
asyncio.run(make_burger())
```

## Параллельный запуск (всё сразу)
**`asyncio.gather()`** — эта функция собирает несколько задач и запускает их одновременно. Пока одна задача ждёт, другие работают.

Представь, что ты заказал бургер и картошку. Повар ставит картошку во фритюр (она жарится 2 минуты), а сам в это время собирает бургер (1 минута). В итоге всё готово за 2 минуты, а не за 3.

**`asyncio.gather()`** — эта команда запускает все задачи сразу. Пример:
```python
async def task(name, sec):
    print(f'Задача {name} началась')
    await asyncio.sleep(sec)  # ждём
    print(f'Задача {name} закончилась')

async def main():
    await asyncio.gather(
        task('Бургер', 2),
        task('Картошка', 1),
    )

asyncio.run(main())
# Картошка закончится раньше, но обе готовились одновременно!
```

## Зачем это нужно?
Асинхронность нужна, когда программа много **ждёт**: скачивает файлы из интернета, ждёт ответа от сервера, читает большой файл. Если код просто считает математику — асинхронность не поможет.

## 📌 Запомни главное

| Что | Как |
|---|---|
| Асинхронная функция | `async def имя():` |
| Точка ожидания | `await что_то` |
| Запустить | `asyncio.run(main())` |
| Несколько задач сразу | `await asyncio.gather(...)` |
| Пауза | `await asyncio.sleep(1)` |
| Где полезно | Много запросов в сеть одновременно |

> 💡 **Главное:** `await` говорит Python: «Я подожду здесь, а ты пока займись другими задачами».
