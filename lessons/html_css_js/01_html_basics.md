# 1. HTML — Каркас документа и базовый текст

HTML (HyperText Markup Language) — это язык разметки, который создает **скелет** страницы. Браузер читает HTML и рисует то, что ты видишь.

## Обязательный каркас
Любая HTML-страница должна иметь такую структуру. Без неё браузер может неправильно отобразить сайт.

```html
<!DOCTYPE html> <!-- Говорит браузеру, что это HTML5. Пишется самой первой строкой. -->
<html lang="ru"> <!-- Корневой тег. lang="ru" означает, что текст на русском. -->

<head>
    <!-- Служебная зона. Пользователь её НЕ видит. -->
    <meta charset="UTF-8"> <!-- Кодировка. Без неё русский текст станет кракозябрами. -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Чтобы сайт нормально выглядел на телефоне. -->
    <title>Моя страница</title> <!-- Название вкладки в браузере. -->
    <link rel="stylesheet" href="style.css"> <!-- Подключаем файл со стилями (CSS). -->
</head>

<body>
    <!-- Всё, что видит пользователь, пишется здесь -->
    <h1>Привет, мир!</h1>
</body>
</html>
```

### Разбор тегов из каркаса:
- **`<!DOCTYPE html>`** — техническая инструкция для браузера. Всегда первая.
- **`<html>`** — главный контейнер, внутри которого лежит вообще всё.
- **`<head>`** — «мозг» страницы. Здесь настройки, название вкладки и подключение стилей. Пользователь это не видит.
- **`<body>`** — «тело» страницы. Всё, что видно на экране (текст, картинки, кнопки), находится здесь.

## Заголовки (h1 – h6)
Заголовки делят текст на смысловые блоки. У них есть уровни: от самого главного до самого мелкого.

```html
<h1>Главный заголовок (один на страницу!)</h1>
<h2>Заголовок раздела</h2>
<h3>Подраздел</h3>
<h4>Под-подраздел</h4>
<h5>Ещё меньше</h5>
<h6>Самый мелкий</h6>
```

> 💡 **Важно:** `<h1>` должен быть на странице только один. Он говорит поисковикам (Google) и скринридерам (для слепых), о чём весь сайт.

## Абзацы и переносы
**`<p>`** — создает абзац. Браузер сам добавляет отступы сверху и снизу, чтобы текст не слипался.
**`<br>`** — принудительный перенос на новую строку (одиночный тег, без закрывающего).
**`<hr>`** — горизонтальная линия-разделитель (одиночный тег).

```html
<p>Это первый абзац текста. Он будет отделен от других отступом.</p>
<p>Это второй абзац.<br>А здесь мы сделали принудительный перенос строки.</p>
<hr> <!-- Линия-разделитель -->
```

## Форматирование текста (очень важно)

| Тег | Что делает | Почему важно |
|---|---|---|
| `<strong>` | Делает текст **жирным**. | Говорит поисковикам: «Этот текст очень важный». |
| `<b>` | Делает текст **жирным**. | Просто для красоты, без смысловой нагрузки. |
| `<em>` | Делает текст *курсивом*. | Говорит поисковикам: «На этом слове акцент». |
| `<i>` | Делает текст *курсивом*. | Просто для красоты (часто для иконок). |
| `<u>` | Подчеркивает текст. | Устарел, лучше `text-decoration: underline` в CSS. |
| `<s>` или `<del>` | ~~Зачеркивает текст~~. | Показать старую цену или удаленный текст. |
| `<mark>` | Подсвечивает текст желтым маркером. | Как будто провели маркером. |
| `<small>` | Делает текст мелким. | Для сносок или копирайта. |
| `<sub>` | Нижний индекс (H<sub>2</sub>O). | Для химии или математики. |
| `<sup>` | Верхний индекс (x<sup>2</sup>). | Для степеней. |
| `<code>` | Показывает текст моноширинным шрифтом. | Для фрагментов программного кода. |
| `<pre>` | Блок кода с сохранением всех пробелов и переносов. | Для больших кусков кода. |
| `<blockquote>` | Цитата (с отступом слева). | Для высказываний. |
| `<abbr>` | Аббревиатура (при наведении показывает расшифровку). | Например, HTML. |

```html
<p>Формула воды: H<sub>2</sub>O</p>
<p>Площадь: 5 м<sup>2</sup></p>
<p><strong>Внимание!</strong> Это <em>очень</em> важно.</p>
<p>Старая цена: <del>1000 руб.</del>, новая: <mark>799 руб.</mark></p>
<p>Чтобы напечатать привет, используй <code>print('Привет')</code>.</p>
<p><abbr title="HyperText Markup Language">HTML</abbr> — язык разметки.</p>
```

## Типичные ошибки новичка

```html
<!-- ❌ Забыли закрывающий тег -->
<p>Текст<p>Ещё текст

<!-- ✅ Правильно: у каждого тега своя пара -->
<p>Текст</p>
<p>Ещё текст</p>

<!-- ❌ Заголовок h3 без h2 перед ним (ломает иерархию) -->
<h1>Главная</h1>
<h3>Подраздел</h3>

<!-- ✅ По порядку -->
<h1>Главная</h1>
<h2>Раздел</h2>
<h3>Подраздел</h3>

<!-- ❌ Несколько h1 на странице (плохо для SEO) -->
<h1>Заголовок 1</h1>
<h1>Заголовок 2</h1>
```

> ⚠️ **Правило:** один `<h1>` на страницу. Заголовки идут по порядку (h1 → h2 → h3). Теги всегда закрывай.

## 📌 Запомни главное

| Что | Тег |
|---|---|
| Каркас документа | `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` |
| Заголовки | `<h1>` – `<h6>` (h1 — один на страницу) |
| Абзац | `<p>` |
| Перенос строки | `<br>` |
| Линия-разделитель | `<hr>` |
| Жирный важный | `<strong>` |
| Курсив акцент | `<em>` |
| Зачёркнутый | `<del>` |
| Подсветка | `<mark>` |
| Код | `<code>` (в строке), `<pre>` (блок) |
| Цитата | `<blockquote>` |

> 💡 **Правило:** если текст важный и жирный — `<strong>`. Если просто жирный — `<b>`. Поисковики это учитывают.
