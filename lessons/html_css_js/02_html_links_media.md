# 2. HTML — Ссылки, картинки и медиа

## Ссылки (`<a>`)
Тег **`<a>`** (anchor) создает гиперссылку. Без него интернет не был бы паутиной.

Главный атрибут — **`href`**. Он указывает, куда ведет ссылка.

```html
<!-- Ссылка на другой сайт -->
<a href="https://google.com">Перейти в Google</a>

<!-- Ссылка на страницу внутри твоего сайта -->
<a href="/about.html">О нас</a>

<!-- Открыть в новой вкладке -->
<a href="https://youtube.com" target="_blank" rel="noopener noreferrer">YouTube</a>

<!-- Ссылка на email или телефон -->
<a href="mailto:info@site.ru">Написать нам</a>
<a href="tel:+79001234567">Позвонить</a>
```

| Атрибут | Что делает |
|---|---|
| `href` | Куда ведет ссылка (обязательный). |
| `target="_blank"` | Открывает ссылку в новой вкладке. |
| `rel="noopener noreferrer"` | Безопасность для `_blank` (чтобы новый сайт не мог управлять твоей страницей). |
| `download` | Скачивает файл по ссылке, а не открывает его. |

## Изображения (`<img>`)
Тег **`<img>`** вставляет картинку. Это одиночный тег, у него нет закрывающего.

Главные атрибуты — **`src`** (путь к картинке) и **`alt`** (текстовое описание).

```html
<img src="photo.jpg" alt="Фотография собаки" width="500" height="300">
```

| Атрибут | Что делает |
|---|---|
| `src` | Путь к файлу (обязательный). Может быть локальным (`img/pic.png`) или ссылкой из интернета. |
| `alt` | Текст, если картинка не загрузилась. **Обязателен** для слабовидящих и поисковиков. |
| `width` / `height` | Ширина и высота в пикселях. |
| `loading="lazy"` | Загружать картинку только тогда, когда до неё долистают (экономит трафик). |

### Картинка с подписью
**`<figure>`** — контейнер для картинки и её подписи. **`<figcaption>`** — сама подпись под картинкой.

```html
<figure>
    <img src="cat.jpg" alt="Кот">
    <figcaption>Мой кот Барсик спит днем</figcaption>
</figure>
```

## Видео и аудио
HTML5 умеет проигрывать видео и звук без сторонних плагинов.

**`<video>`** — для видео, **`<audio>`** — для звука. Атрибут **`controls`** добавляет кнопки управления (play, pause, громкость).

```html
<video src="movie.mp4" controls width="600"></video>
<audio src="sound.mp3" controls></audio>
```

## Встраивание чужих страниц (`<iframe>`)
**`<iframe>`** позволяет вставить на свою страницу другую страницу. Часто используется для YouTube или карт.

```html
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0"></iframe>
```

## Типичные ошибки новичка

```html
<!-- ❌ Забыли alt у картинки -->
<img src="photo.jpg">

<!-- ✅ alt обязателен -->
<img src="photo.jpg" alt="Фото собаки">

<!-- ❌ Ссылка без href (не работает) -->
<a>Кликни меня</a>

<!-- ✅ Правильно -->
<a href="https://google.com">Кликни меня</a>

<!-- ❌ target=_blank без rel (уязвимость) -->
<a href="https://site.com" target="_blank">Сайт</a>

<!-- ✅ С защитой -->
<a href="https://site.com" target="_blank" rel="noopener noreferrer">Сайт</a>
```

> ⚠️ **Правило:** у картинки всегда `alt`, у ссылки — `href`, а с `target="_blank"` всегда добавляй `rel="noopener noreferrer"`.

## 📌 Запомни главное

| Что | Тег / атрибут |
|---|---|
| Ссылка | `<a href="URL">текст</a>` |
| Новая вкладка | `target="_blank"` |
| Безопасная ссылка | `rel="noopener noreferrer"` |
| Картинка | `<img src="..." alt="...">` |
| Размер картинки | `width`, `height` |
| Ленивая загрузка | `loading="lazy"` |
| Картинка с подписью | `<figure>` + `<figcaption>` |
| Видео | `<video controls>` |
| Аудио | `<audio controls>` |
| Встроить страницу | `<iframe src="...">` |

> 💡 **`alt` обязателен!** Без него скринридеры (для слепых) не смогут объяснить, что на картинке. Это не только про SEO.
