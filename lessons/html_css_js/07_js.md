# 7. JavaScript — полный справочник

JavaScript делает страницу **живой**: реагирует на клики, меняет текст без перезагрузки, отправляет запросы на сервер.

## Переменные

**`let`** — создаёт изменяемую переменную (можно перезаписать).
**`const`** — создаёт константу (нельзя перезаписать).

```javascript
let age = 20;
age = 21;          // можно

const PI = 3.14;
// PI = 3;         // ОШИБКА: константу нельзя менять
```

## Типы данных

| Тип | Пример |
|---|---|
| Число | `42`, `3.14` |
| Строка | `'привет'`, `"мир"` |
| Логический | `true`, `false` |
| Массив | `[1, 2, 3]` |
| Объект | `{ name: 'Аня', age: 20 }` |
| null | `null` (пусто) |
| undefined | `undefined` (не задано) |

## Операторы

```javascript
10 + 3;      // 13
10 - 3;      // 7
10 * 3;      // 30
10 / 3;      // 3.333...
10 % 3;      // 1 (остаток)
2 ** 10;     // 1024 (степень)

'5' == 5;    // true (нестрогое, сравнивает только значение)
'5' === 5;   // false (строгое, сравнивает и тип)
```

## Условия

**`if`** — если условие истинно, выполняется код. **`else`** — иначе. Пример:
```javascript
let age = 18;
if (age >= 18) {
  console.log('Взрослый');
} else {
  console.log('Ребёнок');
}
```

## Циклы

**`for`** — повторяет код заданное количество раз. Пример:
```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}
```

## Функции

**`function`** — создаёт функцию. **`return`** — возвращает результат. Пример:
```javascript
function add(a, b) {
  return a + b;
}
console.log(add(2, 3));  // 5
```

**Стрелочная функция `() => {}`** — короткая запись. Пример:
```javascript
const add = (a, b) => a + b;
console.log(add(2, 3));  // 5
```

## Массивы

| Метод | Что делает |
|---|---|
| `.push()` | Добавить в конец |
| `.pop()` | Удалить с конца |
| `.map()` | Преобразовать каждый элемент |
| `.filter()` | Оставить только подходящие |
| `.reduce()` | Свернуть в одно значение |
| `.forEach()` | Пройтись по каждому |

```javascript
const nums = [1, 2, 3, 4];
nums.map(x => x * 2);       // [2, 4, 6, 8]
nums.filter(x => x % 2 === 0); // [2, 4]
nums.reduce((s, x) => s + x, 0); // 10
```

## Работа с DOM (страницей)

**`document.querySelector()`** — находит элемент по CSS-селектору. Пример:
```javascript
const btn = document.querySelector('.btn');
```

**`.textContent`** — меняет текст. **`.style`** — меняет стиль. Пример:
```javascript
btn.textContent = 'Новый текст';
btn.style.color = 'red';
```

**`.addEventListener()`** — добавляет обработчик события (клик, наведение). Пример:
```javascript
btn.addEventListener('click', () => {
  alert('Кнопка нажата!');
});
```

## Работа с формами

**`.value`** — читает, что ввёл пользователь. Пример:
```javascript
const input = document.querySelector('#name');
console.log(input.value);
```

## localStorage — сохранение в браузере

**`localStorage.setItem()`** — сохраняет данные в браузере. **`getItem()`** — читает. Пример:
```javascript
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme');
```

## fetch — запросы к серверу

**`fetch()`** — отправляет запрос на сервер и возвращает ответ. Пример:
```javascript
fetch('https://api.github.com/users/octocat')
  .then(response => response.json())
  .then(data => console.log(data.name));
```

> ✅ **Правило:** используй `const` по умолчанию, `===` вместо `==`, и `addEventListener` для событий.

## Типичные ошибки новичка

```javascript
// 1. Путаница между == и ===
console.log('5' == 5);    // true (приводит типы)
console.log('5' === 5);   // false (сравнивает типы — правильно!)

// 2. Забыли let или const
// x = 10;  // Работает, но создает глобальную (плохо)
let x = 10;  // правильно

// 3. Стрелочные функции и this
const obj = {
  name: 'Аня',
  greet() {
    console.log(this.name); // 'Аня' — обычный метод
  },
  greetArrow: () => {
    // console.log(this.name); // undefined — у стрелочной свой this
  }
};

// 4. Забыли вызвать функцию
function sayHi() { console.log('Привет'); }
sayHi;   // Ничего — просто ссылка на функцию
sayHi(); // Вызов — сработает

// 5. Асинхронность: fetch возвращает Promise
// const data = fetch(url).json(); // ОШИБКА
const data = await fetch(url).then(r => r.json()); // правильно
```

> ⚠️ **Правило:** используй `===` вместо `==`, всегда пиши `let` или `const`, и не забывай круглые скобки при вызове функций.

## 📌 Запомни главное

### Переменные и типы
| Что | Как |
|---|---|
| Изменяемая | `let x = 5;` |
| Константа | `const PI = 3.14;` |
| Число | `42`, `3.14` |
| Строка | `'hi'`, `` `шаблон ${x}` `` |
| Логическое | `true` / `false` |
| Массив | `[1, 2, 3]` |
| Объект | `{ name: 'Аня', age: 20 }` |

### Работа с DOM
| Что | Как |
|---|---|
| Найти элемент | `document.querySelector('.btn')` |
| Найти все | `document.querySelectorAll('li')` |
| Поменять текст | `el.textContent = 'новый'` |
| Поменять стиль | `el.style.color = 'red'` |
| Добавить класс | `el.classList.add('active')` |
| Убрать класс | `el.classList.remove('active')` |
| Создать элемент | `document.createElement('div')` |
| Вставить в страницу | `parent.appendChild(child)` |
| Удалить | `el.remove()` |

### События
| Что | Как |
|---|---|
| Клик | `el.addEventListener('click', fn)` |
| Ввод | `el.addEventListener('input', fn)` |
| Отправка формы | `form.addEventListener('submit', fn)` |
| Запретить стандарт | `event.preventDefault()` |

### Полезное
| Что | Как |
|---|---|
| Сохранить в браузере | `localStorage.setItem('k', 'v')` |
| Прочитать | `localStorage.getItem('k')` |
| GET-запрос | `fetch(url).then(r => r.json())` |
| Вывести в консоль | `console.log(...)` |

> 💡 **`===` vs `==`:** всегда используй `===` (сравнивает тип и значение). `==` приводит типы и ведёт себя странно.
