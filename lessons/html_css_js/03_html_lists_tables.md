# 3. HTML — Списки и таблицы

## Маркированные списки (`<ul>`)
**`<ul>`** (unordered list) создает список с точками (буллитами). Внутри него лежат элементы списка **`<li>`** (list item).

```html
<ul>
    <li>Яблоко</li>
    <li>Банан</li>
    <li>Апельсин</li>
</ul>
```

## Нумерованные списки (`<ol>`)
**`<ol>`** (ordered list) создает список с цифрами. У него есть атрибуты:
- `type="1"` (цифры), `type="A"` (большие буквы), `type="a"` (маленькие), `type="I"` (римские)
- `start="5"` (начать нумерацию с 5)

```html
<ol>
    <li>Разогреть сковороду</li>
    <li>Разбить яйцо</li>
    <li>Пожарить</li>
</ol>

<ol type="A" start="3"> <!-- Начнется с C -->
    <li>Третий пункт</li>
    <li>Четвертый пункт</li>
</ol>
```

## Список определений (`<dl>`)
Используется для терминов и их расшифровок. **`<dt>`** — сам термин, **`<dd>`** — его определение.

```html
<dl>
    <dt>HTML</dt>
    <dd>Язык разметки для создания скелета сайта</dd>
    <dt>CSS</dt>
    <dd>Язык стилей для оформления сайта</dd>
</dl>
```

## Таблицы (`<table>`)
Таблицы нужны для отображения табличных данных (например, расписания или цен).

- **`<table>`** — сам контейнер таблицы.
- **`<tr>`** (table row) — одна строка таблицы.
- **`<th>`** (table header) — ячейка-заголовок. Текст в ней жирный и выровнен по центру.
- **`<td>`** (table data) — обычная ячейка с данными.
- **`<thead>`**, **`<tbody>`**, **`<tfoot>`** — логические части таблицы (голова, тело, подвал).

```html
<table border="1">
    <thead>
        <tr>
            <th>Имя</th>
            <th>Возраст</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Аня</td>
            <td>20</td>
        </tr>
        <tr>
            <td>Иван</td>
            <td>25</td>
        </tr>
    </tbody>
</table>
```

### Объединение ячеек
- **`colspan="2"`** — объединяет ячейку по горизонтали (на 2 столбца).
- **`rowspan="2"`** — объединяет ячейку по вертикали (на 2 строки).

```html
<table border="1">
    <tr>
        <th colspan="2">Общая оценка</th> <!-- Занимает 2 колонки -->
    </tr>
    <tr>
        <td>Математика</td>
        <td>5</td>
    </tr>
    <tr>
        <td>Физика</td>
        <td>4</td>
    </tr>
</table>
```

## Типичные ошибки новичка

```html
<!-- ❌ Используем таблицу для вёрстки (устарело) -->
<table>
  <tr><td>Меню слева</td><td>Контент справа</td></tr>
</table>

<!-- ✅ Для вёрстки — CSS (flex/grid), таблицы — только для данных -->

<!-- ❌ Забыли <li> внутри списка -->
<ul>
  Яблоко
  Банан
</ul>

<!-- ✅ Каждый пункт — в <li> -->
<ul>
  <li>Яблоко</li>
  <li>Банан</li>
</ul>
```

> ⚠️ **Правило:** таблицы — только для табличных данных (цены, расписания). Для вёрстки используй CSS.

## 📌 Запомни главное

### Списки
| Что | Тег |
|---|---|
| Маркированный (точки) | `<ul>` |
| Нумерованный (1, 2, 3) | `<ol>` |
| Пункт списка | `<li>` |
| Список определений | `<dl>`, `<dt>`, `<dd>` |
| Нумерация буквами | `<ol type="A">` |
| Начать с 5 | `<ol start="5">` |

### Таблицы
| Что | Тег |
|---|---|
| Таблица | `<table>` |
| Строка | `<tr>` |
| Ячейка-заголовок | `<th>` |
| Обычная ячейка | `<td>` |
| Шапка / тело / подвал | `<thead>` / `<tbody>` / `<tfoot>` |
| Объединить по горизонтали | `colspan="2"` |
| Объединить по вертикали | `rowspan="2"` |

> 💡 **Таблицы — только для данных.** Для вёрстки (расположения блоков) используй CSS (flex/grid), а не таблицы.
