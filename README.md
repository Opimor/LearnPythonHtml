### 🚀 Как запустить

```bash
git clone https://github.com/Opimor/LearnPythonHtml.git
cd LearnPythonHtml
pip install -r requirements.txt
python app.py
```

Открой **http://localhost:5000**

Windows: двойной клик по ```start.bat```

### 📁 Структура проекта

```
LearnPython/
```
